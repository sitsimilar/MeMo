## 启动（Python 3.10+，无需安装第三方库）

解压后进入 agent-memory-explorer 文件夹：

```sh
python server.py --db ./test-data/validation.sqlite --port 8765
```

Windows 可用 `py server.py`。浏览器打开 http://127.0.0.1:8765 。数据库自动创建于本项目 data/explorer.sqlite，不访问旧项目。停止使用 Ctrl+C。端口被占用时使用 `python server.py --port 8767`。

## 审核路径

1. 输入范围、两个逗号分隔的模块、经历原文、合成／非合成标识，保存。
2. 验证记录同时出现在列表与星云中；刷新页面检查持久化。
3. 拖动空白旋转，滚轮缩放；单击节点或列表查看来源和版本；展开原文证据。
4. 用关键词和数据标识筛选。
5. Shift 拖动节点后观察布局版本增加、内容与组织版本不变。
6. 切换主题确认内容不变。主题目前仅为本页面会话设置，不持久化。

此视图使用 Canvas 绘制三维坐标的透视投影，无 WebGL、力导向或真实语义集群；初始位置为确定性排列。选中记录旁的虚线表示来源证据示意，无自动语义关系。所有记录来自实际来源接口，不预装示例数据。

## 决策与边界

为交付可离线运行的基础增量，本批使用Python标准库HTTP服务，而非原拟FastAPI；无第三方安装要求。后续可替换HTTP层，SQLite数据契约独立。当前单进程串行处理；仅监听回环地址，无多用户鉴权，不适合公开部署。范围筛选不是访问权限隔离；界面可读取本地所有范围。

内容、组织、布局各自版本独立。原始来源单独版本。合成标识独立于认识类型与审核状态。策略API保存组成规则及合并轨迹；当前规则集合有限、预算调用硬限0，不是完整策略编辑器。审核内核只用于契约测试，未暴露生产审核接口，不宣称满足完整证据与人工保护校验。
