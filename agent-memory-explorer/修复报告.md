# r2 独立审核问题修复

本轮不含模型调用、WebGL或GPT接入。

| 问题 | 修复 | 验证 |
|---|---|---|
| 负半径导致画布停止 | 投影先检查相机深度，<=50或非有限坐标直接裁剪；绘制用finally续订动画，异常清除点击缓存并显示错误 | Node直接执行实际project与draw函数，验证z=-1000、近裁剪及异常续帧；真实Chromium待复测 |
| 在A查看时录入B仍显示A | 保存后切到返回节点范围、清除筛选、选中新记录并提示保存范围 | 语法检查通过；浏览器待复测 |
| JSON []断连 | 所有POST先检查顶层对象；内核也检查 | HTTP实测[]、null、字符串、数字均400 JSON，服务继续工作 |
| auto_apply排列顺序覆盖禁止 | 首条形成选择，之后布尔AND，false优先；轨迹记录最终选择 | true/false排列组合测试通过；自动提交仍检查当前暂停状态 |
| 录入缺乏幂等 | Idempotency-Key与请求正文和结果同事务保存；同键同内容返回原ID，不同内容409；前端失败重试复用键 | 内核重复/冲突/不同键测试；HTTP重启后重试仍返回同ID |
| 无内容历史 | 002迁移建立content_history；新增与接受后记录对应版本 | 迁移旧库当前v4、后续v1/v2正文测试通过 |
| 详情状态写死 | 读取epistemic、review映射显示，未知值保留原值 | 语法检查，浏览器待复测 |
| README旧计数 | 更新26项并补相关命令 | 与实际运行一致 |

结果：Python 26项通过；Node语法检查和投影测试通过；真实HTTP五来源、多模块、布局版本、重启持久化、原文保真、400错误及幂等重启测试通过。首次迁移测试因新增002而仍期待单版本失败，已改为检查[1,2]且重复初始化不新增记录，重跑通过。

限制：幂等键是显式请求身份，不按正文全库去重；不带键的请求仍视为独立录入。前端键只在页面当前会话保留，刷新页面后的重新录入不能认作原请求重试。历史迁移只能保存当前内容，无法恢复过去已覆盖正文。scope仍是本地筛选，不是服务端权限隔离；本轮没有扩大为多用户系统。人工保护及完整证据校验仍未实现。

启动：独立目录进入项目后 `python server.py --db ./test-data/r2-review.sqlite --port 8765`，浏览器 http://127.0.0.1:8765 。现有测试库会自动执行002，建议先保留副本或使用新测试库。

优先浏览器复核：保存合法布局x=0,y=0,z=-1000后刷新，确认其被裁剪、其他节点及重置视角仍可绘制；A范围录入B后应定位B；模拟同键HTTP重试只增加一条；旧纯来源的详情仍明确陈述/未审核。此包未附带数据库、凭据或个人数据。
